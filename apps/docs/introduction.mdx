Open Session is an open-source alternative to Sessionboard: call-for-speakers forms, submission review, a speaker portal, agenda building with conflict detection, and public event widgets. The web app is a client of this same API — nothing it can do is hidden from you.

## The shape of the API

Everything is scoped under one of a few roots:

| Root | Who calls it |
|---|---|
| `/api/v1/events/{event_id}/...` | Organizers managing one event — forms, sessions, speakers, evaluations, agenda |
| `/api/v1/me/...` | The signed-in speaker or reviewer, scoped to their own data |
| `/api/v1/public/...` | Anonymous — the CFP submission form and the five public widgets (sessions, speakers, agenda, itinerary, gallery). No auth required. |
| `/api/v1/auth/...` | Sign-in: request a one-time code, verify it, log out |

Public read endpoints (`/api/v1/public/events/{slug}/program` and friends) never require authentication — that's what backs the embeddable widgets. Everything else needs either a session cookie or an API key.
