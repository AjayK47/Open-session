Open Session is an open-source event programme manager. It keeps the organizer,
reviewer, speaker, and attendee workflows connected from the first submission to
the published agenda.

## One continuous programme workflow

<Steps>
  <Step title="Collect proposals">
    Build a call-for-papers form with sections, participant roles, conditional
    fields, submission limits, and category-based routing.
  </Step>
  <Step title="Review and decide">
    Define weighted criteria, assign reviewers, run multiple evaluation rounds,
    and optionally request an AI-assisted assessment.
  </Step>
  <Step title="Prepare speakers">
    Accepted speakers use their own portal for profiles, headshots, files,
    onboarding tasks, resources, and calendar connections.
  </Step>
  <Step title="Schedule and publish">
    Place sessions across rooms and tracks, resolve conflicts, publish the
    agenda, and embed the public schedule, gallery, or itinerary.
  </Step>
</Steps>

## API access is built in

The React application uses the same REST API available to integrations. Human
users can authenticate with a session cookie, server-to-server integrations can
use scoped API keys, and public programme endpoints require no authentication.

<Note>
  The complete endpoint reference is generated from `openapi.json`, so request
  and response schemas stay aligned with the backend contract.
</Note>
