## Prerequisites

- Node.js 20 or newer
- pnpm
- Python 3.12 or newer
- [uv](https://docs.astral.sh/uv/)

## Start the application

<Steps>
  <Step title="Install dependencies">
    From the repository root:

    ```bash
    pnpm install
    cd apps/api && uv sync && cd ../..
    ```
  </Step>
  <Step title="Create the API environment file">
    ```bash
    cp apps/api/.env.example apps/api/.env
    ```

    The defaults use SQLite, local file storage, and development sign-in codes.
    No email or third-party credentials are required for the first local run.
  </Step>
  <Step title="Apply database migrations">
    ```bash
    cd apps/api
    uv run alembic upgrade head
    cd ../..
    ```
  </Step>
  <Step title="Start the API">
    ```bash
    pnpm dev:api
    ```

    The API runs at `http://127.0.0.1:8000`. FastAPI's local reference is at
    `http://127.0.0.1:8000/docs`.
  </Step>
  <Step title="Start the web application">
    In a second terminal:

    ```bash
    pnpm dev
    ```

    Open `http://localhost:5173`.
  </Step>
  <Step title="Create the organization">
    Enter an email address on the sign-in page. In development, the one-time
    code is returned by the API and shown in the interface. The first signed-in
    user creates the deployment's organization and becomes its owner.
  </Step>
</Steps>

## Verify the installation

```bash
curl http://127.0.0.1:8000/health
```

The expected response is:

```json
{"ok":"true","environment":"development"}
```

<Warning>
  Development codes must not be exposed in production. Production startup also
  requires email delivery and a non-default session secret.
</Warning>

Continue with [Configuration](/configuration) before deploying outside your machine.
